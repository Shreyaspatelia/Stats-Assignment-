Task 4. Write a function or pseudocode that takes a column of data (array of values) from a Flipkart order history and automatically detects 
whether it is likely Nominal, Ordinal, Interval, or Ratio scale. Briefly describe the logic used for each type.<br><br><em><strong>Constraint:
</strong> You do not need to write a perfect algorithm — focus on simple rules based on value types and patterns.</em>

FUNCTION detect_scale(column):

    IF column contains text/categories:

        IF categories have a natural order
           (e.g., "Low", "Medium", "High"):
            RETURN "Ordinal"

        ELSE:
            RETURN "Nominal"


    ELSE IF column contains numbers:

        IF values represent counts or amounts
           where 0 means "none" and ratios are meaningful
           (e.g., Quantity, Price, Discount):
            RETURN "Ratio"

        ELSE IF values are measurements where
                differences are meaningful but 0 is not a true zero
                (e.g., Temperature in °C):
            RETURN "Interval"

        ELSE:
            RETURN "Ratio"   // default for numerical order data


    ELSE:
        RETURN "Unknown"
