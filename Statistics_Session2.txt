Task 4. Write a function or pseudocode that takes a column of data (array of values) from a Flipkart 
order history and automatically detects whether it is likely Nominal, Ordinal, Interval, or Ratio scale. 
Briefly describe the logic used for each type.<br><br><em><strong>Constraint:</strong> You do 
not need to write a perfect algorithm — focus on simple rules based on value types and patterns.</em>

def detect_scale(data):
    if len(data) == 0:
        return "Unknown"

    # Numerical data
    if all(isinstance(x, (int, float)) for x in data):

        if min(data) >= 0:
            return "Ratio"
        else:
            return "Interval"

    # Categorical data
    else:
        ordinal_values = [
            "Low", "Medium", "High",
            "Poor", "Average", "Good", "Excellent",
            "Pending", "Shipped", "Delivered"
        ]

        if all(x in ordinal_values for x in data):
            return "Ordinal"
        else:
            return "Nominal"

# Example Flipkart order data
order_status = ["Pending", "Shipped", "Delivered"]

# Detect the measurement scale
result = detect_scale(order_status)

print("Measurement Scale:", result)

Output:
Measurement Scale: Ordinal
