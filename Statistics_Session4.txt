Task 1. Given the daily step counts of a user for the last 7 days as [6500, 7200, 8000, 6000, 9000, 7500, 8200], calculate the range of steps and 
explain what this tells you about the user's activity pattern

Range = Maximum value − Minimum value
Maximum steps = 9000
Minimum steps = 6000

Range = 9000 − 6000 = 3000 steps

The range of 3,000 steps shows that the user's daily activity varies by 3,000 steps between the least and most active days. Overall, the user's activity

Task 2. For a list of 5 food delivery order amounts on Zomato: [250, 400, 350, 300, 500], write code to compute the variance and standard deviation 
of the order amounts.

First, the mean of the orders is:
Mean = 250 + 400 + 350 + 300 + 500 / 5 = 360

For Variance: comparing each order with 360

250 − 360 = -110
Squared Difference = -110 x -110 = 12,100

400 − 360 = 40
Squared Difference = 40 x 40 = 1,600

350 − 360 = -10
Squared Difference = -10 x -10 = 100

300 − 360 = -60
Squared Difference = -60 x -60 = 3,600

500 − 360 = 140
Squared Difference = 140 x 140 = 19,600

Adding the squared differences:
12,100 + 1,600 + 100 + 3,600 + 19,600 = 37,000

37,000 / 5 = 7,400

Variance = 7,400

Standard deviation is simply the square root of variance:

√7,400 = 86.02325....

Standard Deviation = 86.02


Task 3. You have the monthly mobile data usage (in GB) for a user over 6 months: [3.2, 2.8, 3.5, 3.0, 2.9, 3.1]. Calculate the coefficient of variation 
(CV) and interpret whether the user's data usage is consistent or highly variable.<br><br><em><strong>Hint:</strong> CV = (Standard Deviation /
Mean) × 100%</em>

Calculating the Mean:
Mean = 3.2 + 2.8 + 3.5 + 3.0 + 2.9 + 3.1 = 18.5
Mean = 18.5 / 6 = 3.0833

For Variance: comparing each value with 3.0833

3.2 - 3.0833 = 0.1167
Squared Difference = 0.1167 x 0.1167 = 0.0136

2.8 - 3.0833 = -0.2833
Squared Difference = -0.2833 x -0.2833 = 0.0802

3.5 - 3.0833 = 0.4167
Squared Difference = 0.4167 x 0.4167 = 0.1736

3.0 - 3.0833 = -0.0833
Squared Difference = -0.0833 x -0.0833 = 0.0069

2.9 - 3.0833 = -0.1833
Squared Difference = -0.1833 x -0.1833 = 0.0335

3.1 - 3.0833 = 0.0167
Squared Difference = 0.0167 x 0.0167 = 0.0002

Adding the squared differences:
0.0136 + 0.0802 + 0.1736 + 0.0069 + 0.0335 + 0.0002 = 0.308
0.308 / 6 = 0.0513                   

Variance = 0.0513

Calculating the Standard Deviation: it is square root of variance
Standard Deviation: √0.0513 = 0.2264
Standard Deviation = 0.2264

Calculating the Coefficient of Variation:
CV = Standard Deviation / Mean
CV = 0.2264 / 3.0833
CV = 0.0734

converting into a percentage:
CV = 0.0734 x 100 = 7.34

The coefficient of variation is approximately 7.34%. This indicates that the user's monthly mobile data usage is relatively consistent, with low variation 
over the six months.


Task 4. Suppose you are analyzing the number of likes on 10 recent Instagram posts: [120, 150, 130, 110, 170, 140, 135, 160, 125, 155]. Compute 
the standard deviation and compare it with the mean to comment on the consistency of engagement

Calculating the Mean:
Mean = 120 + 150 + 130 + 110 + 170 + 140 + 135 + 160 + 125 + 155 = 1395
Mean = 1395 / 10 = 139.5

For Variance: comparing each likes with 139.5

120 - 139.5 = -19.5
Squared Difference = -19.5 x -19.5 = 380.25

150 - 139.5 = 10.5
Squared Difference = -10.5 x -10.5 = 110.25

130 - 139.5 = -9.5
Squared Difference = -9.5 x -9.5 = 90.25

110 - 139.5 = -29.5
Squared Difference = -29.5 x -29.5 = 870.25

170 - 139.5 = 30.5
Squared Difference = 30.5 x 30.5 = 930.25

140 - 139.5 = 0.5
Squared Difference = 0.5 x 0.5 = 0.25

135 - 139.5 = -4.5
Squared Difference = -4.5 x -4.5 = 20.25

160 - 139.5 = 20.5
Squared Difference = 20.5 x 20.5 = 420.25

125 - 139.5 = -14.5
Squared Difference = -14.5 x -14.5 = 210.25

155 - 139.5 = 15.5
Squared Difference = 15.5 x 15.5 = 240.25

Adding the squared differences:
380.25 + 110.25 + 90.25 + 870.25 + 930.25 + 0.25 + 20.25 + 420.25 + 210.25 + 240.25 = 3,272.5
3,272.5 / 10 = 327.25

Variance = 327.25

Calculating the Standard Deviation:
Standard Deviation: √327.25 = 18.09
Standard Deviation: 18.09

Comparing the standard deviation with the mean using the coefficient of variation (CV):
CV = Standard Deviation / Mean
CV = 18.09 / 139.5
CV = 0.1296

converting into a percentage:
CV = 0.1296 x 100 = 12.96

The mean number of likes is 139.5, and the population standard deviation is approximately 18.09. The coefficient of variation is approximately 12.96%. 
This indicates that the number of likes varies relatively little compared with the average. Therefore, engagement across the 10 Instagram posts is 
reasonably consistent, although some posts receive more likes than others.
